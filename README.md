# sream-studio

Sream 锦霖的原创中文歌工作流：制作说明 → 文本竞稿 → ACE三种音乐方向 → 分轨 → Suno与平台交付 → 匿名试听选择。

目标是提高作品的记忆点与表达可信度。技术规则负责发现缺陷，六维文本评审负责初筛，实际试听决定旋律、演唱与感染力。

- [SKILL.md](SKILL.md)：任务路由、工作流与交付要求。
- [脚本说明](scripts/README.md)：真实CLI与环境配置。
- [质量与试听](references/12_质量与试听.md)：匿名试听、偏好记录与针对性返工。
- [参数证据](references/13_参数证据.md)：经验适用范围和已撤销假设。
- [共享交付与归档](references/11_产出与归档.md)：同步脚本、逐文件校验与Windows可见性确认。
- [驾车行车 MV](references/16_驾车行车MV.md)：给定一首歌，出「始终在路上」的竖屏歌词 MV（含发布文案）。
- [局部降调修音](references/17_局部降调修音.md)：某个字音高冲高了，只改那几处、其余不动。
- [专辑封面出图](references/18_专辑封面出图.md)：1:1 封面批量候选，中文标题与概语由模型直出。
- [歌曲MV分镜](skills/music-mv-storyboard/SKILL.md)：按真实音频时间轴写导演提示词与分段素材方案。
- [虚拟歌手MV](references/19_虚拟歌手MV.md)：用户选择独立演唱模型时，使用Wan客户端生成镜头。
- [曲风模板索引](references/20_曲风模板卡.md)：按需查外部技能中的中文模板与英文关键词。
- [创作证据与生成记录](references/21_创作证据与生成记录.md)：文件快照、待核实记录草稿与PDF记录恢复。
- `templates/prompts/`：自然表达优先的曲风模板。

用户指定top3×3时交付9条候选；未指定规模时先做一首试作。按任务交付清唱、Suno结构化歌词及平台纯文本。新评审与产出按版本另存，保留历史作品竞争资格。

编排层依赖工作区`tools/`，通过`TOOLS_DIR`指定。`PY`用于选择分析环境。音频服务和模型凭据走环境变量；密钥、服务地址、模型权重、音视频与实际评审资料不进技能仓库。

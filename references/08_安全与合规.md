# 08 · 安全与合规

## 一、密钥红线（req 8，最高优先级）

- ⛔ **任何密钥 / token / 认证信息 / 内网地址，绝不进仓库或文档。**
- 配置一律走**环境变量**或**本地 `.env`**（`.env`、`*.env`、`secrets/` 已被 `.gitignore` 排除）。
- 只提交**变量名 + 占位符**示例（`templates/env.example`），不含真实值。
- 提交前自查：

```bash
git add -A
git diff --cached --name-only   # 逐一看有没有 .env / *.key / *.pem / secrets
# 再扫一遍有没有真实 token 形状
grep -rInE "sk-[A-Za-z0-9]{20,}|Bearer [A-Za-z0-9._-]{20,}|AKIA[0-9A-Z]{16}" . \
  --exclude-dir=.git || echo "✅ 未发现疑似密钥"
```

## 二、发布合规（抖音/汽水）

- 发布必勾抖音「**内容由 AI 生成**」。
- 「使用的 AI 工具」如实选择（Suno / ACE-Step 等）。
- 署名统一：`词/曲/演唱：Sream（AI辅助）`；古诗词注明出处。
- 参考曲只学「技术参数」（速度/调性/频段/配器/结构），**不抄旋律、歌词、歌名**。

## 三、内容不提交（体积 + 版权）

- 模型权重（`.gguf`/`.bin`/`.safetensors`）、音视频成品（`.wav`/`.mp3`/`.mp4`）、
  分轨数据、音乐库 —— 一律本地留档，**不进本仓库**。
- 这些已被 `.gitignore` 兜底，但仍要自觉不 `git add -f` 强加。

## 四、提交前检查清单

- [ ] 没有 `.env` / `*.env` / `secrets/` / `*.key` / `*.pem` 被跟踪
- [ ] 文档里只有变量名，没有真实 IP / 端口 / 密钥
- [ ] 没有模型权重、音视频、分轨数据被跟踪
- [ ] `git status` 里新增的每个文件都能说清「为什么该进仓库」

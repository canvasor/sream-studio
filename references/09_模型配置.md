# 09 · 模型配置与清单

擂台用**多个 LLM 模型**竞稿（歌词 + 曲风）。这里说明配置格式、当前模型清单，以及密钥红线。

---

## 一、配置文件在哪（密钥绝不进仓库）

```
~/.dsh/secrets/llm_models.env      ← 真实配置（含 key，权限 600）
sream-studio/templates/模型配置_模板.env   ← 无密钥模板（对照格式）
sream-studio/templates/模型配置_说明.md    ← 完整格式说明
```

> ⛔ **真实配置留在 `~/.dsh/secrets/`，不迁移、不提交。**
> 本仓库只保留「模板 + 格式说明 + 模型清单」这些**无密钥**部分。

## 二、配置格式（每模型 4 必填 + 2 可选）

```
LLMn_NAME=<模型 id>
LLMn_BASE=<base url，公开 API 端点>
LLMn_PROTO=OpenAI | Anthropic
LLMn_KEY=<api key>
# 可选：
LLMn_TIMEOUT=<秒，默认 600>
LLMn_MAXTOK=<最大输出 token，默认 8000>
```

- `n` 从 1 起、可跳号，脚本扫 1~99，填了 `NAME` 的才生效。
- 任何 **OpenAI / Anthropic 兼容**接口都能进擂台（DeepSeek/百炼/Kimi/GLM/方舟/Gemini…）。
- 填完验一遍：`llm_client.py list` 看是否读到，`llm_client.py test` 逐个真连。

# 10 · 音频服务接口（audio.cpp）

音频能力由本地 **audio.cpp 服务**（HTTP）提供，Python 侧 `WindowsAudioAPI` 客户端调用。
本文档写清**接口端点、能力→模型映射、ACE 出歌参数**；服务地址走 `AUDIOCPP_HOST` / `AUDIOCPP_PORT`，不写进仓库。

> 本机更细的「命令清单 / 常见报错」在 `账号资料/Windows_audio_cpp_命令清单.md` 与
> `账号资料/Windows_audio_cpp_常见报错.md`（含 Windows 端 CLI 用法与模型文件夹名，**不进仓库**）。

---

## 一、HTTP 端点

| 端点 | 方法 | 用途 | 对应能力 |
|---|---|---|---|
| `/health` | GET | 健康检查 | — |
| `/v1/models` | GET | 列出已加载模型 | — |
| `/v1/audio/transcriptions` | POST | 语音转写 | ASR |
| `/v1/audio/alignments` | POST | 歌词对轴 | ForcedAligner |
| `/v1/audio/speech` | POST | 语音合成 / 音色克隆 | TTS / CosyVoice |
| `/v1/tasks/run` | POST | 通用任务（分轨 / 出歌） | HTDemucs / ACE-Step |

请求体对 `/v1/tasks/run` 是 `{"model": <model名>, "request": {...}}`。

---

## 二、能力 → 模型名 → 客户端方法

| 能力 | `model` 名 | GGUF 模型 | 客户端方法 |
|---|---|---|---|
| 出歌 | `music` | ACE-Step1.5-GGUF | `generate()` |
| 分轨 | `sep` | HTDemucs-GGUF | `separate()` |
| 转写 | `asr` | Qwen3-ASR-1.7B-GGUF | `transcribe()` |
| 对轴 | `align` | Qwen3-ForcedAligner-0.6B-GGUF | `align()` |
| 语音合成 | `tts` | Qwen3-TTS-12Hz-1.7B-Base-GGUF | `speak()` |
| 音色克隆 | `clone` | CosyVoice3-GGUF | `clone()` |

> 分轨要求输入 **44.1kHz WAV**（mp3 先转）；转写要求 **16kHz 单声道 WAV**。

## 三、ACE 出歌参数（`generate()` 请求体）

基础请求字段：

| 字段 | 说明 | 默认 |
|---|---|---|
| `text` | 风格提示词（Styles） | 必填 |
| `lyrics` | 歌词 | 必填 |
| `duration_seconds` | 时长 | 必填 |
| `num_inference_steps` | 采样步数 | 8 |

可透传的 `request` 选项（白名单，拼错会被客户端拒绝，不会静默发错）：

| 参数 | 类型 | 作用 | 备注 |
|---|---|---|---|
| `bpm` | int | 目标 BPM | 作曲规格（132/86/…） |
| `keyscale` | str | 目标调性 | |
| `timesignature` | str | 目标拍号 | |
| `retake_seed` | int | 种子 | 出多个不同候选；`-1` 清除 |
| `retake_variance` | float | 种子扰动强度 | |
| `lm_temperature` | float | planner 采样温度 | 默认 0.85，调高=更多变化 |
| `lm_guidance_scale` | float | planner CFG | 默认 2.0 |
| `guidance_scale` | float | ⭐ 扩散 CFG（0~5）| 见下方实测 |
| `shift` | float | 时间步弯曲 | turbo 默认 3.0；1.0 明显劣化 remix |
| `negative_prompt` | str | 负向提示 | 映射 Exclude |
| `enable_thinking` | bool | planner 思考 | 默认 true |
| `sampler_mode` | str | 采样器 | euler / heun |
| `route` | str | 出歌路线 | text2music / complete / remix / … |

### 参数的适用范围

生成参数表达目标，不能保证精确执行。gs=3优势的旧结论已经撤销；当前工作流以1为基线，显式记录覆盖值。历史脉冲实验在分析修复后如需量化结论应重新验证。

非text2music路由依赖正确的源音频契约，当前客户端未完成验证，不靠猜字段名发起生成。更多证据范围见[13_参数证据](13_参数证据.md)。

## 四、时长安全闸

- 安全上界 **240s**；**500s 卡死服务且无法取消，只能重启**。
- 歌词太短 → 「唱完补静音」，文件时长看着对、整体 RMS 正常，只有分段扫描才暴露
  → 出完**必跑** `windows_audio_api.py check <wav>`。

---

## 五、用法（Python 客户端，只依赖标准库）

```python
from windows_audio_api import WindowsAudioAPI
api = WindowsAudioAPI()               # 读 AUDIOCPP_HOST / AUDIOCPP_PORT
api.health(); api.models()
api.transcribe("song_16k.wav")                       # ASR
api.separate("song_44k.wav", "out/stems")            # 分轨
api.generate("风格词", "歌词", "out/song.wav",
             duration=30, request_options={"bpm": 132, "keyscale": "D minor",
                                            "guidance_scale": 1, "retake_seed": 1})
```

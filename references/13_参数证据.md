# 参数与经验的证据范围

每条经验应记录模型/服务版本、曲风、输入片段、样本数量、比较方式和结论范围。历史报告与新工具算法不同，数字不能直接横比。

| 经验 | 当前处理 | 证据范围 |
|---|---|---|
| ACE gs=3一定提高脉冲 | 撤销；生成基线1，可显式调参 | 本地历史6对同种子样本没有支持gs=3优势；修复采样率后如需结论应重测，不能推导所有曲风都必然有害 |
| BPM补偿比固定0.87 | 不作通用默认，基线1.0 | 旧DJ批次经验；慢民谣记录不支持通用补偿 |
| 加强速度文字即可精确控BPM | 仅作可尝试的方向 | 本地批次曾改善速度感，但不保证数字遵循或迁移到新版本 |
| Exclude只能2–4项 | 简短列表作起点，不按项数硬拦 | 起草建议；未在此维护跨版本官方上限证据 |
| Suno所有段落都必须带表演提示 | 按需要写，避免堆标签 | 可表达段落意图，但作用需要成歌验证 |
| [End]可以保证不拖尾 | 仅作提示，检查实际结尾 | 生成器仍可能偏离 |
| 标题出现4次就更抓耳 | 仅报告文本复现，不据此判好听 | 听觉记忆需要旋律与演唱证据 |
| 行末字的爆破声母不宜拖长 | 撤销 | 混淆声母与韵尾；换气和延音不能由此推导 |
| Style Influence 80%等于固定遵循程度 | 记录当次界面值，按任务对照 | 控件百分比不能解释为遵循概率；界面可能随版本变化 |
| Style Influence固定80%、Weirdness固定45% | 作为用户指定的项目默认，后续明确要求可覆盖 | 官方Creative Sliders只说明风格贴合强弱及Weirdness 50%为常规中点，没有“50%丢一半权威”的含义 |
| Variety Normal使提示词完全送不到模型 | 不写成已证实事实；项目默认Off | 需对应版本的官方说明与实际输入对照；控件不存在时如实记录 |
| Max Mode On必然更好或更长 | 用户指定默认On，按当前账户支持情况填写 | 开启偏好不等于质量保证，也不推断所有模型有该控件 |
| Duration Custom必然硬切、赶词 | 用户指定默认Auto，检查实际时长和结尾 | 具体行为取决于界面、功能和模型版本，不能作跨版本定律 |
| Exclude必须以no开头才是否定 | 本项目默认裸元素、不加no | 输入框本身表示排除；裸元素为项目填写约定，不宣称平台绝不理解其他写法 |

若用户要求核实最新平台规则，再查询对应版本的官方资料；不要把项目笔记里的“官方说”直接升级为事实。

界面参数核查来源：[Suno — How to Use: Creative Sliders](https://help.suno.com/en/articles/6141377)（2026-10-17查阅）。项目默认值维护在`templates/suno_more_options.json`，导出时单独生成参数卡，不写进Styles冒充界面设置。

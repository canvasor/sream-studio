# 参考对比与副歌设计

用于“平淡、没有穿透力、没学到参考精髓”等反馈。完整出曲、分轨成功只是技术完成；这一轮应先解决具体的音乐问题。

## 比较实际段落

- 原唱与翻唱优先取同一段歌词；新旧原创取相同功能的主歌、副歌。逐条定位，不能所有文件统一截第60秒，也不能用整曲平均值代替副歌。
- 记录原文件、SHA256、起止时间、歌词锚点、定位方法和不确定性。ASR没有时间戳时，用短片段转写缩小范围，必要时短片段对轴；强制对轴不是歌词存在的证据。
- 同时保留原始响度信息与等响度试听。主副歌反差在同一版本内测量；比较不同版本的音色和冲击力时先匹配响度。两者不要混为一个结论。
- 人声分轨可辅助观察音区、句尾拖音、停顿、频谱；注明分离残留和音高八度错误。频谱更亮不等于更有穿透力，混音级音高不能直接当人声旋律。
- 没有直接聆听能力时说明分析手段；音频理解模型的听感描述标明来源，也需要核实。不给未听作品编造偏好分数。

按需要比较以下维度，不必强填数值：

| 维度 | 具体问题 | 可改变的设计 |
|---|---|---|
| 记忆动机 | 听后能留下哪句、哪组节奏或音高轮廓？ | 核心句的停顿、重音、复现与一个变化点 |
| 演唱 | 哪个字由弱转强，音色怎样变化？ | 清楚的起音、胸混声密度、句尾释放、少量装饰音 |
| 主副歌反差 | 副歌相对主歌改变了什么？ | 音区、节奏密度、元音时值、和声或伴奏留白 |
| 情绪出口 | 副歌在说什么非唱不可的话？ | 从情节推进到呼唤、表白、质问或其他明确行动 |
| 节奏身份 | 人声怎样进入拍点，句间如何呼吸？ | 弱起、切分、长短句应答、停顿后落点 |
| 编曲支撑 | 伴奏是否挡住核心字句？ | 副歌前收束，进入时展开，主旋律处让位 |

“最近火了”的原因需要传播、曝光与听众证据。两份录音只能支持录音差异和创作假设，不能识别爆红原因。

## 把判断转换成生成请求

先填[副歌设计卡](../templates/副歌设计卡.md)，只取本轮最重要的1–2个目标。区分：已观察的差异 → 创作假设 → 这次改变 → 实际音频核查。参考学习的是功能，原创旋律、歌词和声线身份独立设计。

需要强烈副歌时，检查正向词是否反复要求轻柔、克制、放松，负向词是否把开放唱法一并排除了。主歌可以亲近，副歌可以释放；把段落变化写清楚，不用一串形容词同时要求全曲轻柔与爆发。民族乐器和五声音阶不能代替演唱、旋律与节奏设计。

关键表演意图写入实际发送的Styles。某些底层生成工具会把`[Chorus - ...]`归一为`[Chorus]`，必须检查请求预览，不能以Markdown里写过为准。保留Suno输入中的完整结构标签，并核查各平台各自实际输入。

短呼唤、直接表白和增加重复只是选项，不能由“副歌弱”直接推出这些处方。若目标是高远、辽阔、舒展，先按[地域声音设计](15_高原与草原声音设计.md)检查声线、元音展开和旋律呼吸；不要让通用流行hook公式抵消风格身份。

## 先核查方向，再扩展候选

预算为三首各三条时，先出一首或每首第一条作为待选。检查实际演唱、旋律走向、地域特征和主副歌关系，并取得试听对音乐方向的认可，再扩展其余方向。ASR核心句出现、技术完整或声学指标变化不构成音乐通过；缺少实际听辨时明确停在待选状态。候选计数不能迫使失败试作进入正式交付，修订使用新版本目录，不无限重抽。

音乐方向探索可同时改变歌词、演唱与编曲，但应称“组合方案”；只有固定其他条件的对照才可归因到某一个参数。种子或temperature不同不证明音乐方向已落实。

交付新旧副歌等响度对比、完整曲与对齐清唱。旧版本保留；试听选择可暂空，报告写“音乐效果待试听确认”，不能把分析指标或提示词目标写成已经改善的听感结论。

同名新候选的分轨使用[源指纹缓存](06_Suno配置与歌词.md)，不能只换输出批次却继续复用按歌名保存的重采样文件。

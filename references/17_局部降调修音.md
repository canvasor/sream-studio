# 17 · 局部降调修音（某个字音高冲高了）

用于「某个字听起来顶上去了、应该落下来」这类**单点旋律瑕疵**。
只改那几个字，其余部分一个采样都不动。

## 什么时候用

- 副歌结尾某个字**突然上挑并停在高位**，听着"顿一下 / 顶上去"
- 一个字或两三个字，而不是整句、整段跑调
- ⚠️ 不适合：整句走音、节奏错、音色不对 —— 那些只能重出

## 第一步：定位（**别信 ASR 和歌词对轴**）

⛔ 血的教训：ASR 只给整段文字、没有时间戳；强制对轴（align）对**长窗口**会给
压缩到 0.08s 的碎时间戳，按它改会改错地方（实测第一次就改错了 1 秒多）。

✅ **正确方法：看基频（F0）轨迹**，找"突然上挑并保持在高位"的位置。

```python
# 20ms 帧、40ms 窗、自相关估 F0，只在有能量的帧上算
hop, win = int(sr*0.02), int(sr*0.04)
ac = np.correlate(fr - fr.mean(), fr - fr.mean(), mode="full")[win-1:]
k = lo + int(np.argmax(ac[lo:hi]))          # lo ~ sr/800, hi ~ sr/90
if ac[k] > 0.35*ac[0]: f0 = sr/k
```

判读要点：
- **「平稳段 → 跳高 → 保持」** 就是问题点。实测一例：前一字 372Hz 平着，
  问题字跳到 471Hz 并停住 → 高 4 个半音，听着就是"上去了"
- 想确认改对没：改完再测同一区间，中位应落到目标（如 471→353 = 降 5 半音）
- ⚠️ 自相关会有**八度误判**（471 被算成 121、800 是搜索上界）——
  看**相邻帧的连续性**和"整段是否一致"来排除，别只看单个数字

## 第二步：变调（保共振峰）

用 ffmpeg 的 `rubberband`，**必须 `formant=preserved`**：
否则音色会变闷/变男声，像换了人。

```bash
ffmpeg -i seg.wav -af "rubberband=pitch=<ratio>:formant=preserved:transients=crisp" out.wav
# ratio = 2^(semitones/12)
```

## 第三步：贴回原曲

不要用 `concat` 拼（接缝处容易爆音）。**在波形数组里替换区间 + 余弦交叉淡化**：

```python
env = ones(n); env[:nf] = 0.5 - 0.5*cos(pi*r); env[-nf:] = 0.5 + 0.5*cos(pi*r)
out[i0:i1] = full[i0:i1]*(1-env) + shifted*env
```

- 淡化 60ms 一般够；太长会把前后字也削掉
- 区间要**覆盖整个问题字 + 它的拖尾**，但**别越过下一个字的起音**
  （下一个字一进来就断，否则会把后一个字也降调）
- 多段连续应用时，每段都基于**当前结果**，不要重复读源文件

## 命令

```bash
python3 scripts/patch_pitch.py --in song.wav --out fixed.wav \
    --patch 63.22:64.86:-5 --patch 127.20:128.86:-5 --patch 172.52:174.15:-5 \
    --fade 0.06
# 先看改哪：--dry-run
```

## 变调量怎么选

| 情况 | 建议 | 听感 |
|---|---|---|
| 只想去掉"上挑感" | -4 半音（落回前一字同级）| 平着收住 |
| 想有**收束感** | **-5 半音**（略低于前一字）| 往下落，最自然 |
| 想做成明显下滑 | 分段递降（-4/-5/-7）| 更像真唱，但易有拼缝 |

⭐ 实测 -5 最稳（用户选定方案 B）。

## ⚠️ 硬限制：会有轻微"顿挫"

`rubberband` 变调会改变元音的瞬态，改完**多少带一点顿挫/金属感**，
尤其问题字正好在**人声最亮的位置**时。

**做到这一步就够了**：把旋律改对，剩下的交给**重出**——
在 Suno 里用同一份 Lyrics + Styles 重新生成，让它自然唱出正确的旋律走向。
修音是用来**救急/验证方向**的，不是用来出正式母带的。

## 实测案例（2026-10-18《青稞熟了茶还烫》）

| 位置 | 问题 | 改法 |
|---|---|---|
| 63.22–64.86s | 「方」471Hz 停在高位（「远」只有 372Hz） | -5 半音 → 356Hz |
| 127.20–128.86s | 同上 | -5 半音 |
| 172.52–174.15s | 同上（末段「远方才是远方」） | -5 半音 |

定位过程：ASR 分段找到三次「远方」→ 基频细查确认是**「方」**而不是「远」→
只改「方」及其拖尾。改后三处都落到 ~350Hz，走向与用户录的参考（190→140Hz，-5 半音）一致。

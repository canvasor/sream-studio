# 音频上传与母版选择

## 保留ACE，先选候选再使用额度

ACE、本次Suno作品和纯文本生成都是可用来源。先试听选出值得保留的旋律、唱法或编配，再决定下一步：

| 当前状态 | 下一步 |
|---|---|
| ACE成品已满意 | 可直接交付，不要求再经过Suno |
| ACE旋律或演唱方向满意，希望尝试另一种成品 | 选该版本作音频母版，上传后尝试Cover或当前界面支持的编辑 |
| Suno已有满意作品 | 保留该作品继续编辑，不必回到ACE |
| 尚无满意母版，或需要新方向 | 可用Suno纯文本生成，与ACE候选分别试听 |

不要把全部本地候选自动送进Suno，也不因一次失败删除ACE路线。上传和后续生成是不同操作，不能承诺上传后生成免费；执行前以当前界面显示的消耗为准。

默认每条ACE候选都先备齐配置，是否实际上传由试听选择决定。`ace_three.py`自动导出到`<out>/suno/<音频stem>/`：`00_Suno参数卡.md`将上传类型、描述框文案、十个类型选项、操作建议和More Options放在一起；`Audio_Description.txt`供直接复制，`More_Options.json.audio_upload`记录同样信息及源文件SHA256。不会自动上传或使用Suno额度。手动导出与覆盖参数见[06](06_Suno配置与歌词.md)。

## 上传类型：按实际音频内容选择

以下是依据界面标签含义的选择建议，不是经官方证实的模型内部路由。不要靠切换类型来保证音质、旋律锁定或声线克隆。

| 类型 | 适合的内容 |
|---|---|
| Full Song | 有完整歌曲结构的录音，包含完整ACE主唱与伴奏成品；制作粗糙也可以结构完整 |
| Song Demo | 旋律/歌曲草稿，例如一段哼唱配和弦、主副歌小样或从完整版截出的创作参考段 |
| Voice | 单独的人声、清唱或分离后的人声片段；不等同于启用声音克隆 |
| Instrument Stem | 单独的乐器声部，例如吉他或钢琴分轨 |
| Loop | 为循环使用准备的短音乐段落 |
| Rhythm / Percussion | 鼓、打击乐或节奏素材 |
| Sample | 其他短采样素材；已有更明确类型时优先按实际内容选 |
| Spoken Word | 说话或朗诵 |
| Sound Effect | 音效 |
| Field Recording / Ambience | 实地录音、环境氛围声 |

完整ACE混音不因“由本地模型生成”就必须选Song Demo。对普通人声加伴奏的整曲，Full Song是直接选择；若实际只上传草稿段，就按Song Demo描述。页面仍显示Uploading Clip时先等待上传成功，再Continue；出现失败信息则处理失败，不把点击Continue当成上传完成。

## Describes the contents怎么填

这个框描述**文件里实际有什么**：人声/乐器、语言、速度感、是否整曲以及录音特点。想让新作品怎样唱、如何编配，另写Styles和歌词结构；不要把愿望当成源音频已具备的特征，也不用把ACE模型名作为风格词。

以下示例仅适用于实际包含普通话女声与伴奏的完整文件；如是男声、清唱或局部段落，要相应改写：

```text
Full-length Mandarin song with female lead vocals and instrumental accompaniment. Includes verses, choruses, an instrumental interlude and an outro.
```

清唱示例（确认实际为分离人声后使用）：

```text
Isolated Mandarin singing vocal excerpt with no intentional instrumental accompaniment. Separated from a full mix; some separation artifacts may remain.
```

只填能听到或有来源记录的内容，不猜BPM、调性、音域或已经实现某地域唱法。此框不替代Styles、Lyrics或Audio Influence。

## Continue之后：先决定用途

- **Cover**：以已上传歌曲尝试再演绎或换编配，适合保留原曲方向的目标；仍可能改变旋律、声线和段落，要与母版试听比较。
- **Extend**：从已有音频接着生成，适用于续写；不等同于整首重新制作。
- **局部编辑**：当前模型和账户支持时，优先用于已有满意母版的局部返工。
- **纯文本Create**：不启用音频参考；文字约束不会指定唯一旋律。不能把仅上传到曲库等同于已在本次生成中使用。

记录源文件SHA256、上传选段的原曲起止时间、类型、内容描述、实际操作/模型以及所有实际滑块值。有音频输入时才记录Audio Influence；不设通用必胜数值。比较它的效果时固定母版、文字和其他设置，只改变该项，并保留一次生成的全部候选。风格贴合、旋律保留和听感偏好分开评价。

## 资料与证据边界

2026-10-18核查官方[Audio Uploads](https://help.suno.com/en/articles/6141569)：音频可上传到曲库，之后用于Extend、Cover等；文档当时写明Basic最多60秒、Pro/Premier最多8分钟，实际限制以当前界面为准。[Creative Sliders](https://help.suno.com/en/articles/6141377)确认音频上传时有Audio Influence，但没有给出上述内容分类的完整行为或通用最优值。分类建议依据用户展示的页面标签，不宣称已经验证各类别的内部模型机制。

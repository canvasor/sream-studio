# 18 · 专辑封面出图（1:1 批量候选）

给一张 EP/专辑出 **1:1 封面候选（常做 8 版）**，中文标题与概语尽量让模型直出。

## 先查风格库

**动笔写 prompt 之前**，先加载 `gpt-image-2-style-library` 技能（`references/style-library.md`），
按「模板类别 → 风格标签 → 场景标签」选型。常用几类：

| 想要 | 模板 |
|---|---|
| 电影感实拍 / 牧场 / 街拍 | `realistic-photography`（写实摄影） |
| 标题就是主视觉 | `conceptual-typography-poster`（概念字体海报） |
| 人影与风景叠印 | `ink-double-exposure-poster`（水墨双重曝光） |
| 手绘 / 淡雅 | `illustration-art-style`（插画与艺术风格） |

选型后按下面 5 个块写 prompt，**不要凭记忆拼风格词**。

## 两条出图通道

| 通道 | 模型 | 适用 | 怎么调 |
|---|---|---|---|
| **GPT-Image**（默认）| `gpt-image-2.5-flare` / `-sunburst` | 中文文字准、构图稳 | `llm_client.gen_image` |
| **豆包 Seedream** | `doubao-seedream-5.0-pro` / `-lite` | 实拍质感强 | `byted-ark-seedream-skill` 的 `generate.js` |

两条都能出，按需选；**不要在同一次任务里混用**（风格不统一）。

## ⛔ 六个坑（都踩过）

1. **尺寸必须写进提示词**
   `llm_client.gen_image` 的 `size` 参数**实测无效**，真正起作用的是提示词里的画幅描述
   （函数内部 `with_aspect` 只是帮你补一句，**你自己写更保险**）。
   开头就写「**正方形 1:1 构图的音乐专辑封面**」。

2. **Seedream 的 `--size 2K` 出的是横图（3136×1344）**
   做方形封面要**显式传 `1920x1920` / `2048x2048`**；
   硬下限 **总像素 ≥ 3,686,400**（1920² = 3,686,400 正好够）。

3. **Seedream 默认加水印**
   `--watermark false`，否则右下角有「AI生成」。

4. **Seedream 默认存 `~/Desktop/Seedream-Images`**
   该目录常不存在 → `ENOENT`。必须给 `ARK_SEEDREAM_SAVE_PATH`。

5. **颜色会跑偏（尤其偏黄）**
   高原/草原题材默认容易出夕阳暖调。**明确写**「主色为清透的蓝天与青绿草甸，
   白云蓬松，**不要偏黄、不要夕阳暖调、不要室内**」。

6. **中文文字必须逐张核对**
   GPT 实测能正确渲染（8/8 无错字），但**不能假设**。
   用 `album_covers.py --sheet` 出的 `_文字核对.jpg`（标题+概语区裁切放大）逐张看。

## 提示词结构（5 块）

```
正方形 {aspect} 构图的音乐专辑封面。            ← ① 画幅（必须）
{场景：地点 + 主体 + 前景/中景/远景}              ← ② 画面
主色为{palette}。                                ← ③ 配色（写给"不要什么"最有效）
{风格：实拍/水彩/版画 + 镜头 + 光}                ← ④ 风格
画面上方居中写中文大字「{专辑名}」，下方写一行中文小字「{概语}」，
字体简洁端正、文字清晰、不要错字、不要英文、不要水印。   ← ⑤ 文字约束
```

要点：
- **概语是文案，不是装饰** —— 一句 12 字以内，能和专辑概念对上
- 8 版要**风格真不同**（实拍 / 极简 / 航拍 / 剪影 / 静物 / 水彩 / 长焦 / 版画），
  只换场景不换风格 = 8 张一样的图
- 文字位置固定（上方标题、下方概语），便于后续统一裁切与叠字

## 命令

```bash
# 看会发什么（不联网）
python3 scripts/album_covers.py --jobs templates/专辑封面_题单.json --out /tmp/cov --dry-run

# 真出图 + 总览图 + 文字核对图
python3 scripts/album_covers.py --jobs jobs.json --out DIR --sheet

# 换豆包
python3 scripts/album_covers.py --jobs jobs.json --out DIR --provider seedream --model pro
```

题单格式见 `templates/专辑封面_题单.json`（`album / aspect / outsize / jobs[]`）。
`jobs` 已存在的图会**自动跳过**，可反复跑补失败的几张。

## 归档

```
账号资料/专辑_<专辑名>/封面/          ← 8 版候选 + 00_封面候选.md（概语/风格对照）+ _总览.jpg
作品库/<NN_歌>/03_封面/方形_1x1_*.jpg ← 单曲平台封面（各歌 1 张）
```

作品说明里加一行指向候选目录，避免以后重复出图。

## 实测记录（2026-10-18《高原三帖》）

- 8 版，GPT-Image `gpt-image-2.5-flare`，单张 40–46 秒，1920×1920
- 标题「高原三帖」+ 8 句不同概语，**逐张裁切放大核对，零错字**
- 首版单曲封面用 Seedream 出，**偏黄**（酥油茶/青稞两张），第二轮改「蓝天白云草原牧场」后明显改善
- 结论：**颜色要在 prompt 里明确否定暖调**，光靠"自然光"不够

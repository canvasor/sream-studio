# 19 · 虚拟歌手 MV（独立 Wan 接口）

用户明确选择「图＋人声驱动演唱镜头」时使用本分支。若用户选择图片＋歌曲音频直接交给视频平台，先用[歌曲MV分镜](../skills/music-mv-storyboard/SKILL.md)，不自动转为分轨和独立口型模型。

## 构图与生成顺序

- 先核实人物、歌曲版本、音频起止、画幅与目标平台，沿用本次已确认素材。横屏和竖屏都可按需求设计，不沿用旧项目的16:9默认。
- 先确认分镜与静帧，再生成短样片；使用当前模型实际支持的低成本参数。低清与高清可用分辨率需要分别核实，不假定每种模型都能从480P升到1080P。
- 演唱镜头保持嘴部清楚、面部足够大；动作按情绪与唱词安排。静止演唱也可自然，长音或强演唱时减少复杂动作；行走、远景和航拍按叙事需要使用。
- 歌词与音频以真实时间轴为准，按乐句和器乐空隙切段。生成视频的音轨不自动等于原母版；最终合成是否沿用原曲按任务要求决定。

## 客户端与配置

`scripts/wan_client.py`使用Python标准库，支持`face-detect`、`s2v`、`video`、`poll`和`download`。环境变量优先；也可读取本地`~/.dsh/secrets/asr_models.env`，凭据不入仓库：

```text
ASR_MODEL_API_KEY=<your-api-key>
ASR_MODEL_BASE_URL=https://example.invalid/api/v1
VISION_MODEL_S2V_NAME=wan2.2-s2v
VISION_MODEL_VIDEO_NAME=wan3.0-video-prime
```

两个模型名是当前客户端的历史默认值，不代表每个账号、地域或网关都支持。`face-detect`目前复用`VISION_MODEL_S2V_NAME`，检测接口要求的模型名应按目标服务核实。提交前检查目标接口的模型、分辨率、单次音频/视频时长、图片角色及费用；本文不把单次实测或截图当跨版本能力保证。

客户端将本地媒体临时上传，并设置OSS资源解析请求头。临时上传端点当前固定为DashScope中国站公开地址；若使用其他地域或代理，先确认该凭据、模型及上传端点兼容。HTTP(S)与`oss://`输入按原值发送；是否可抓取取决于目标服务和媒体地址，不宣称所有外部URL均不可用。临时文件的有效期按服务说明核实。

## 预览与执行

```bash
# 离线预览：不读凭据、不上传、不提交任务；参数能力仍须另行核实
python3 scripts/wan_client.py s2v --image /path/to/person.jpg \
  --audio /path/to/vocal-phrase.wav --resolution 480P --out /path/to/s01.mp4 --dry-run
python3 scripts/wan_client.py video --prompt '草原微风，镜头缓慢推进' \
  --image /path/to/landscape.jpg --duration 5 --resolution 480P \
  --ratio 16:9 --out /path/to/s02.mp4 --dry-run
```

核实参数后移除`--dry-run`执行。示例480P是拟提交参数，不保证目标模型接受。`video`命令保留历史默认1080P，实际生成应明确传入已核实的`--resolution`；s2v画幅与图片、分辨率参数和服务裁切规则有关。

```bash
# 检查人物图片是否适合当前演唱接口，不把同步调用等同于免费
python3 scripts/wan_client.py face-detect --image /path/to/person.jpg --dry-run

# 查询已有任务，不重新提交
python3 scripts/wan_client.py poll --task-id example-task-id
python3 scripts/wan_client.py download --task-id example-task-id --out /path/to/s01.mp4
```

`--no-wait`在提交后返回任务编号，后续用`poll`和`download`查询。轮询超时不表示任务已取消，不要因此重复提交。下载先写临时文件，传输完成后才发布；已有目标拒绝覆盖，改用新文件名。

## 验收与记录

先验收短样片的身份、口型、构图、长音和动作，再决定扩展。若目标模型不支持交付分辨率，另选已确认可用的路径；本地放大也不等于原生高清。最终检查镜头交界、音轨连续、字幕与封面版本。实际任务编号、技术抽查、成本和环境故障排查记录留在仓库外；共享参考只维护可复用步骤和适用范围。

# 歌曲 MV 分镜导演

将真实歌曲片段、角色图和创作意图转成可以交给视频平台执行的导演提示词。用户选择“图＋音频直接生成”时沿用此路径，不自动改为分轨、独立口型模型和多工具合成。

## 输入与音频锚点

- 核实歌曲版本、源文件、起止时间、人物、画幅、目标平台。优先沿用用户已指定的角色和版本；未明确的平台限制列为待核实，不阻塞可完成的分镜。
- 用 ffprobe 核实时长，截取原片段，保留源文件指纹及源曲/片段双时间轴。默认不变速、不重唱、不改词曲、不添加对白或伴奏；有声参考生成不等于原轨会被逐样本保留。
- 先找对应版本的歌词和对齐文件；没有时进行转写与听辨。检查同音字、重复副歌、长尾音、换气与器乐空隙。ASR 时间戳只是估计，不能把模型描述的秒数当测量值。
- 标记时间证据：`asr_estimate`、`forced_alignment`、`manual_listening`、`unverified`。自动对齐也需抽查；无可靠逐字证据就写乐句级区间，强调以输入音频实际起止为准。没有音频时只交未对轴草案。

## 写镜头与表演

1. 先定一个可见的情感变化与空间关系，让动作由唱词和音乐推动。怀念可以是欲抬手又收回、看向远路；不把每个名词都演成手势。
2. 区分**镜头切换**和**同镜头内表演节拍**。同一跟拍镜头中换视线不算新镜；写明人物与摄影机的位置、方向、速度、构图和起终状态。
3. 每个乐句安排一个主要动作，其余保持低强度延续。唱词、呼吸、视线、手部、镜头和环境各有职责；强演唱时减少走动、甩头和复杂运镜。留出尾音，不按字数机械闭嘴。
4. 演唱主体面部足够大、嘴无遮挡，优先正面或轻微三分之二角度。背影、航拍、远景可做叙事镜，不能同时声称可验收精细口型。静止演唱也可自然，不强制行走或大幅手势。
5. 角色图用于身份还是首帧要明确。身份图的纯色背景无需复现；首帧图则决定初始空间。服装、配饰、道具、风向、时间和光线跨段连续。比例按本次需求，不沿用旧项目横屏默认。

## 平台适配与交付

阅读 [导演提示词与平台适配](references/prompt-pattern.md)，输出素材绑定表、完整可粘贴提示词、双时间轴表和简短操作说明。实际分析记录和媒体放仓库外。

- `@人物`、`@音频`是待映射引用，不是假想平台语法。说明应在平台真正插入对应素材；API角色字段与网页控件分别核实。
- 查当前目标入口的单次输出时长、参考音频时长、图片角色、音频生成方式；本地其他 API 文档不能作为豆包网页上限的证明。超限按乐句和器乐空隙拆分，各段使用对应裁切音频及从零开始的提示词，附起终姿态衔接。
- 用户提出10秒/15秒等限制时，将其作为当前分段上限，而非只解释支持切分。交付每段音频与独立提示词、段序和拼接说明，并用`--max-seconds`核验；规划细节见参考中的“短时长入口”。
- 未知上限时交完整导演稿和标明条件的短段方案，不宣称整段可一键生成。分段是否复用尾帧由平台能力决定；不能保证身份和连续镜头无缝。
- “口型百分百同步”“不换脸”“原轨完全保真”作为目标或验收项，不能当已经实现的事实。不写无法执行的逐帧嘴形指令，也不以堆叠要求替代清晰表演。
- 默认只制作分镜与素材包；用户要求实际生成时才使用已配置生成技能。不要因有参考素材自动提交付费任务。

需要可校验时间表时，采用 [时间表契约](references/timeline-format.md)，运行：

```bash
python3 scripts/timeline.py /path/to/timeline.json --max-seconds 10 --table /path/to/分镜时间轴.md
```

脚本检查区间覆盖与引用，不证明歌词听辨正确或平台执行成功。生成视频后优先验收开头、长音、重复副歌及分段交界的口型；比较原轨与输出的时长、旋律/歌词和声音，记录漂移区间，再只修改主要失败点。

上例路径相对于本技能目录；从`sream-studio`仓库根目录调用时使用`python3 skills/music-mv-storyboard/scripts/timeline.py ...`。

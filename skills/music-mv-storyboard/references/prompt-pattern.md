# 导演提示词与平台适配

## 可粘贴结构

开头只保留生成需要的信息，不塞入分析过程：

```text
画幅与风格：9:16，纪实电影感，单一连续镜头，无字幕与额外文字。
素材绑定：@人物图用于同一角色身份/服装参考；@歌曲片段是本段唯一演唱与音乐依据。
声音：按参考歌曲的原有歌词、旋律、速度、声线和伴奏演唱；画面跟随声音。
场景与构图：具体空间、光线、人物与道具位置、摄影机起始景别。
镜头1/连续跟拍/0–Xs：摄影机与人物的相对运动；面部和嘴的可见性。
表演节拍/0–as/实际唱词：一项主要动作、视线与情感，说明尾音处理。
表演节拍/as–bs/实际唱词或器乐：延续状态或一次有动机的变化。
结尾：依实际尾音/下一句关系确定停留或继续，不编造告别对白。
约束：身份、服装、空间和光照稳定；不新增角色抢唱，不额外配乐或对白。
```

不要照抄示例的所有细节。抬手、转头、走动、背景人物、动物、镜头运动同时发生会抢走执行能力；情绪可由一次目光变化承担。背景运动选一两项即可。物件在画面中晃动不代表必须新增其音效。

## 歌曲声音的两种任务

**现成歌曲 MV**：原唱声线由参考音频决定。不要另外指定“60岁男烟嗓”等冲突声线。平台即便支持音频参考，也可能重建音轨、改变歌词或仅借用氛围；操作说明中区分期望与实际支持，生成后检查。

**重新演唱/改编视频**：只有用户明确要求时才给新声线、曲风或对白。将新旧声音的优先级写清，不能同时要求原轨严格保留和声音重做。

## 上传与分段

- 给每个素材清楚的名称、用途和必要的源时间。只选择本段歌曲裁切，不让模型在整首歌里自行寻找。
- 身份参考图优先清楚的正面或轻侧面半身；若界面只有首帧模式，背景与构图会受原图影响。可先让平台按身份参考建立首帧，但这属于另一操作，不能假定已经完成。
- 只把当前段音频和该段提示词绑定。第二段从0秒起算；不要贴整曲绝对时间要求短片模型等待。
- 切点选乐句后间隙，跨段持续的长音与动作要另查。保留一条完整原片段用于核对，分段文件不单独变速或加淡入淡出。
- 按平台可用上限选择分段数，不强制固定三镜或固定秒数。如果限制暂不清楚，给一个明确“适用于上限至少N秒”的备用方案。
- 多段生成的连续性需要实际验收。平台支持尾帧参考时可延续机位、人物位置与表情；不支持时可设计有动机的剪切，不能谎称一镜到底。

## 短时长入口：10秒、15秒及固定档位

1. 取视频输出上限与参考音频上限的较小值作为切分上限。片段长度可以小于上限，不要求凑满。先选乐句间隙、换气或器乐过渡，避免在长音和连续口型中间切开。
2. 若一句本身长于上限，先查是否可在句内呼吸处分开；必须切延音时标记风险，可考虑在该处安排叙事镜头遮掩视觉接缝，但原音轨时间不能缩短。不能为满足上限漏掉唱词。
3. 分段音频无缝覆盖源片段。每段提示词重置为0秒，保留当前歌词、进入姿态、结束姿态、机位和情绪，不在每段都重新“开场”和“唱罢”。校验片段序列及累计时长，保留完整音轨作母版。
4. 示例33秒：上限15秒可选14＋9＋10秒；上限10秒可选5.5＋8.5＋9＋10秒。此例依赖这首歌的乐句，不作为其他歌曲的固定分段公式。
5. 上限10秒不一定支持任意5.5/8.5秒。若界面只允许固定5/10/15秒档位，先核实参考音频是否自动拉伸、循环或截断。允许时使用下一可用档位，并明确歌曲按原速唱完后只保持余下画面，再裁去多余视频；若必须补静音后滚，另存上传副本并记录有效歌曲区间。不要拉伸母版音频来凑时长。
6. 平台支持时以上段尾帧衔接下段。若只接受一张参考图，需在身份图与尾帧间按平台能力选择；不支持时用有动机的剪切。尾帧中嘴若处于张开状态，下段按实际音频衔接，不能强制静闭嘴起唱。
7. 最终顺序拼接并以完整原歌曲片段作一条连续主音轨，关闭各段重建声音可减少音色和音量接缝；先检查视频与原轨速度和词序一致，再替换，换音轨不能修复已经漂移的嘴形。不要盲目交叉淡化演唱画面导致双嘴重影，亦不要独立淡入淡出每段歌曲。

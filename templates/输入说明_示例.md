# 输入说明 · 示例

流水线「形态 A · 歌曲制作说明」的填写示例。照这个结构写即可，不必全填。

```markdown
主题：戏班最后一场演出，人比戏更苦
立意：拆楼前夜，老艺人最后一次上台，把「戏比天大」唱给自己
歌词要点：
  - 场景：戏台 / 油彩 / 锣鼓 / 散场
  - 副歌记忆句：「戏比天大」
  - 情绪：克制 → 爆发
曲风：国风摇滚
目标：132 BPM，D 小调
人声：男声，副歌带戏腔呐喊
参考曲：无
```

## 字段说明

| 字段 | 必填 | 不填会怎样 |
|---|---|---|
| 主题 / 立意 | ✅ | 擂台阶段没方向，模型各写各的 |
| 歌词要点 | ✅ | 同上 |
| 曲风 | ✅ | 由擂台按「学习」阶段补，但可能偏离你预期 |
| 目标 BPM / 调式 | ⚪ | 曲风定了后由 ACE 阶段定 |
| 人声 / 演唱形式 | ⚪ | 默认男声独唱 |
| 参考曲 | ⚪ | 不填 = 不学任何单曲，只学音乐库规律 |

## 提示

- **不要**只给一句话让模型自由发挥——那等于没输入。
- **副歌记忆句**一定要写，这是擂台 hook 评分的核心。
- 曲风词尽量用 `chinese-songwriter-skill` 里的标准英文关键词，喂 ACE/Suno 更稳。
